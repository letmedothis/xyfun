# NET-005

## Original Issue
Plugin System Executes Untrusted Code via workerpool. Plugins are installed with `ignoreScripts: false`, meaning npm lifecycle scripts are executed during installation.

## Root Cause
The `npminstall()` call used `ignoreScripts: false`, allowing npm scripts (preinstall, install, postinstall) to run during plugin installation. A malicious plugin could execute arbitrary code during installation.

## Fix
Changed `ignoreScripts: false` to `ignoreScripts: true` in the npminstall call.

## Files Changed
- `src/main/services/PluginService.ts`

## Behavior Before
1. Plugin installation triggers npm lifecycle scripts
2. Malicious preinstall script executes arbitrary code
3. Plugin code is then loaded via workerpool

## Behavior After
1. Plugin installation skips npm lifecycle scripts
2. Only the plugin's main module is loaded
3. Install-time code execution is prevented

## Test Added
Regression verified by existing test suite passing.

## Validation
- `pnpm typecheck:node` - PASS
- `pnpm typecheck:web` - PASS
- `pnpm lint` - PASS
- `pnpm test` - PASS (100 tests)

## Regression Risk
LOW - Some plugins may rely on npm scripts for legitimate setup (e.g., native module compilation). These plugins will need to handle setup differently.

## Remaining Risk
Runtime code execution via `import(modulePath)` still occurs. Plugins still have full Node.js capabilities when running.
