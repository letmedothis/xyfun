# NET-006

## Original Issue
Puppeteer Script Injection via User-Controlled Scripts. CMS play endpoint returns `script` object with `runScript`/`initScript` fields that are directly interpolated into JavaScript code executed in Puppeteer page context.

## Root Cause
User-controlled script content from CMS adapters is directly interpolated into template strings that are executed via `evaluateOnNewDocument`. The `${runScript}` variable is injected without sanitization.

## Fix
**PARTIAL** - Added security logging when custom scripts are executed. The fundamental issue (executing remote code) is by design for the CMS adapter system and requires code signing or sandboxing.

## Files Changed
- `src/main/services/CdpElectron.ts`

## Behavior Before
Custom scripts executed without any logging or validation.

## Behavior After
Security warning logged when custom scripts are executed, including script length for audit trail.
